# 🎵 The Mayhem - Projeto Web Acessível

![Banner](https://upload.wikimedia.org/wikipedia/commons/e/ed/Mayhem_Logo_718x358.png)

> Um site acessível dedicado ao álbum *Mayhem* da Lady Gaga (2025), com foco em design inclusivo e experiência do usuário aprimorada.

---

## 🌟 Sobre o Projeto

O **The Mayhem** é um site interativo que apresenta informações sobre o álbum *Mayhem* da cantora Lady Gaga.  
Este projeto não apenas exibe conteúdo multimídia, como também implementa **recursos de acessibilidade**, garantindo que usuários com diferentes necessidades possam navegar e interagir com o site.

O site é **responsivo**, totalmente funcional em dispositivos móveis e desktops, e utiliza efeitos de animação suaves com **ScrollReveal.js** para uma experiência mais envolvente.

---

## 🔍 Funcionalidades Principais

- Seções bem estruturadas:
  - Início com boas-vindas e botão de acesso rápido
  - Sobre o álbum *Mayhem* com texto descritivo e fonte de referência
  - Galeria de imagens da turnê e apresentações
  - Formulário de contato funcional
- Menu de navegação fixo
- **Recursos de acessibilidade**:
  - Botão de aumento e diminuição da fonte
  - Alternar contraste de cores (alto contraste)
  - Navegação por teclado (`tabindex`)
  - Uso de atributos `aria` para leitores de tela
  - Imagens com `alt` descritivo
- Animações com **ScrollReveal.js** para revelar seções de forma elegante
- Layout responsivo utilizando **Bootstrap 5**

## 🛠 Recursos de Acessibilidade

O site foi desenvolvido pensando em **inclusão digital**:

1. **Menu de acessibilidade**
   - Aumentar/diminuir fonte
   - Alternar contraste de cores
2. **Atributos ARIA**
   - `aria-label` e `aria-expanded` para descrição de elementos interativos
3. **Tabindex**
   - Seções e botões navegáveis via teclado
4. **Imagens com texto alternativo**
   - Descrição detalhada de cada imagem
5. **Alto contraste**
   - Facilita a leitura para pessoas com deficiência visual
